# Мамандықтар (Профессии)

Детская обучающая игра для балабақша «Нұрсәуле», группа «Балауса».

Ребёнок нажимает на здания на карте города, собирает пазл профессии и отвечает на вопросы.

## Что на сайте

- **Главный экран** — карта города с 7 зданиями
- **7 профессий:** пожарный, врач, учитель, повар, строитель, полицейский, парикмахер
- Для каждой профессии: пазл из 5 частей + викторина с картинками-ответами
- **Финал** — картинка после прохождения всех 7 профессий

Язык интерфейса: қазақша (казахский).

## Как открыть

Онлайн (GitHub Pages): ссылка появится после публикации Pages.

Локально: открой папку любым простым сервером, например:

```bash
npx --yes serve .
```

## Как заменить фотографии

Все картинки лежат в папке `images/`.

1. Открой файл **`images/IMAGES.json`** — там полный список: имя файла, где на сайте видно, размер в пикселях.
2. Подготовь своё фото **того же имени** (например `hero-city-map.jpg`).
3. Замени файл в папке `images/` (имя файла не меняй).
4. Или просто пришли мне фото и скажи имя из списка — я подставлю.

## Технологии
